# Obsidian clean tracker plan

## Purpose
The tool's purpose is to help the user visualize how 'cluttered'
their obsidian vault is based off of a set of 'rules'.

## Sample rules that are initially included in the tool
- Orphan count 
- Count of non template compilant notes

## Technical Details
Rules will be a set of Typescript files.
One Typescript file = one rule, where one rule matches a set of files
